# Quick Launch & Helper Scripts

These scripts make running and updating the **Image Grid Slicer** as simple as a double-click!

---

### 🍏 On macOS (Double-Click in Finder)

| Script | Action |
| :--- | :--- |
| **`Run App.command`** *(or `run.command`)* | Launches the app. Automatically checks for a virtual environment (`env`), verifies dependencies, and opens the GUI. |
| **`Update (Git Pull).command`** *(or `git_pull.command`)* | Pulls the newest updates from GitHub (`git pull`) and updates required Python packages. |
| **`Install & Setup.command`** *(or `setup.command`)* | Creates the `env` virtual environment from scratch and installs all dependencies. |

> **Tip**: In macOS Finder, you can double-click any `.command` file just like a regular app!

---

### 🪟 On Windows (Double-Click in File Explorer)

| Script | Action |
| :--- | :--- |
| **`run.bat`** | Launches the app in Python. |
| **`update.bat`** | Pulls latest changes and updates dependencies. |
